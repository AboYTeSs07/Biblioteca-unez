# 📚 Sistema de Gestión Bibliotecaria - UEZ

Sistema integral para el control de catálogo de libros, préstamos, devoluciones, usuarios (estudiantes y docentes) y cálculo de multas para la biblioteca de la **Universidad Emiliano Zapata**.

## 🛠️ Stack Tecnológico
* **Lenguaje:** C# (.NET WinForms)
* **IDE:** Visual Studio 2022
* **Base de Datos:** MySQL / WampServer
* **Arquitectura:** N-Capas (UI, BLL, DAL)
* **Control de Versiones:** Git & GitHub

---

## 🚀 Módulos del Sistema
1. **Autenticación y Roles:** Control de acceso diferenciado (Admin, Personal, Docente, Estudiante).
2. **Catálogo e Inventario:** Control dinámico de existencias e ISBN.
3. **Gestión de Transacciones:** Préstamos y devoluciones en menos de 3 clics.
4. **Control Financiero:** Cálculo automático de multas por entrega extemporánea.
5. **Dashboard e Indicadores:** Reportes de rendimiento y gráficas en tiempo real.
